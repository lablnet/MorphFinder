### **2. Description** *(Max 4,000 characters)*

```text
MorphFinder is a next-generation file manager designed for speed, flexibility, and intuitive navigation. Built with a unified core and a runtime-switchable Tri-UI engine, MorphFinder lets you experience file browsing your way.

KEY FEATURES:

• Tri-UI Shell Engine: Switch effortlessly between three iconic layout styles on the fly:
  - Finder: Standard macOS unified toolbar, sidebar, path bar, and column views.
  - Explorer: Windows-style command bar, address bar, and details pane.
  - Dolphin: Split views, places panel, and embedded terminal workflow.

• Fast File System Operations: Lightning-fast directory indexing, real-time file monitoring, and instant search capabilities.

• Custom Themes & Design: Beautiful dark and light modes built with modern design system principles, responsive micro-animations, and customizable layout density.

• Rich Preview & Metadata: Instant file previews, thumbnail generation, detailed file inspector, and path breadcrumbs.

• Tabbed & Split Navigation: Open multiple tabs or side-by-side split panels to organize, copy, and move files across locations seamlessly.

MorphFinder brings desktop file management into a clean, modern, and ultra-flexible workspace.
```
